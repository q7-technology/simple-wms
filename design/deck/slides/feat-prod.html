Production and scanning

Production orders

  • Pick components with the same engine, drop at a line-side location, event production.components_issued
  • Scan the production order to put away finished goods, pallet by pallet, running total against expected
  • Batch comes from the order's QR code: read-only on screen, blocked if missing or mismatched
  • Over-receipt tolerance with supervisor badge
  • Per-warehouse switch: has the ERP already counted the goods receipt? If yes, bins only and no event

One scan parser

  • Tries GS1 (QR, DataMatrix, GS1-128, Digital Link), then JSON in a QR, then per-site custom patterns, then plain text lookup
  • Handles the group separator character and symbology prefixes
  • One code can fill product, batch and quantity at once
  • Each screen says what it expects: scanning a shelf when it wanted a product gives a friendly message
  • Unknown scans are logged with raw text so a new pattern can be built from real examples
  • Runs on the scanner for speed and behind POST /v1/scans/parse for other systems
