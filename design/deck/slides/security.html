Security

Three kinds of visitor, three kinds of key

Office staff · desktop

Username and password or single sign-on (OIDC). Short-lived session token plus refresh. Optional 2FA for admins.

Floor operators · scanner

Badge scan or operator ID plus PIN. Known devices only. Idle logout, lockout after 5 wrong tries. Supervisors create accounts, IT audits them.

Other systems · API

One scoped API key per system: what it can do, at which warehouses, for which owner. Rotatable, revocable, hash stored, optional IP allowlist. Outbound webhooks HMAC-signed.

Permissions

Roles are bundles: picker, receiver, supervisor, inventory controller, admin, integration. Every check asks: this role, this warehouse, this owner?

Supervisor badge

Short ship, stock adjustment, over-tolerance receipt: a supervisor scans their badge on the same scanner, like a manager key at a checkout.

Audit

Every ledger line and task stores who, which device, when. Logins, failed logins, key use and permission changes go in a log nobody can edit. Users are deactivated, never deleted.
