Technical stack

Python back end, React front ends

API · Python 3.12 + FastAPI

Async, typed with Pydantic, OpenAPI for free. Chosen so pyrfc is available if an SAP RFC bridge is ever needed. SQLAlchemy 2 + Alembic migrations.

Database · PostgreSQL 16

One database. Ledger as an append-only table with a trigger that blocks UPDATE and DELETE. Row-level owner filter ready for 3PL.

Queue · Postgres table + worker

Events and print jobs in a durable table, a Python worker with backoff. No Redis or RabbitMQ until volume says so.

Desktop · Vite + React + Tailwind

TypeScript. Tables, detail panels, task board. Talks to the same API as everyone else.

Scanner · PWA (Vite + React + Tailwind)

Same repo, second entry point. Installable on Zebra and Honeywell Android scanners, service worker caches the app shell so it opens offline, keyboard-wedge and camera scan input, current task held in memory with a retry queue for Wi-Fi drops. Updates roll out on next launch, nothing to install by hand.

Hosting · Ubuntu + Docker Compose

api, worker, db, caddy (TLS), desktop and scanner as static builds. Secrets in a .env on the host. Nightly pg_dump plus whole-VM backup.

Q7 Technology · Simple WMS build brief · 17

Python rather than TypeScript on the API purely for pyrfc. Everything else is what I already run.
