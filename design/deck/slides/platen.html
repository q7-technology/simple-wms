Fixed data shapes

One documented JSON shape per document type: location label, product label, carton label, pick list, packing slip, transfer docket, pallet label. Adding a field is a new version; old versions keep working.

Same queue as events

If Platen is asleep, the job waits and retries. Nothing vanishes. Status is stored against the task and a reprint sends the same data as a new job.

Redesign without touching the WMS

The WMS knows what happened. Platen knows what it looks like. Change a label layout in Platen and the WMS never notices.
